## Binding qualifications

- **Speech stop is logical settlement, not physical exit.** Error/exit/timeout can synthesize the same stopped event. Cleanup precedes sink and finish callbacks; a thrown callback can leave the Promise unresolved. Original tests explicitly allow timeout settlement while termination never resolves. Keep physical ownership and `live / unverifiable / exited` separate.
- **Cloud dictation is not discard-only cancellation.** Nonempty finish clears retained chunks before the HTTP call, uses no AbortSignal/deadline, and reads the key at request time. Empty finish skips model/key validation. The maximum audio counter advances before rejection; fallback statusText is not passed through the dedicated sanitizer. Preserve source characterization and separate corrected privacy/cancellation regressions; no cloud call occurred.
- **Key existence is not usable/decryptable-secret proof.** The process cache, raw-versus-legacy decoding, encryption-availability branch and plaintext fallback are source behavior, not approval to use that fallback in Drogon. Requested0600 creation mode does not establish existing-file mode or Windows ACL protection. No actual key files were read.
- **Cache migration is best effort, not transactional.** Existing targets are trusted by existence; fixed `.partial` siblings and `stat` recursion do not establish concurrent-copy isolation, symlink-cycle defense, fsync, ownership or integrity. Preserve non-ASCII Windows compatibility while testing those failure modes explicitly.
- **Download counters are not a stream byte budget.** Resume metadata/header totals and post-download size checks precede separate SHA verification; that hash stream has no cancellation signal. Idle timeout is not an overall deadline. At the outer retry entry, equal partial size returns before another request, with later integrity verification owned by ModelManager. Tests must distinguish transport completion, hash acceptance and installation. No remote bytes were downloaded.
- **Audio chunk bounds are not universal allocation bounds.** The source can combine already-buffered samples before splitting, and retains references supplied by callers. Resampling invalid/nonpositive rates returns the input; the two original resampler tests only establish downsample lengths and same-rate identity. Native inference, audio quality, upsample boundaries and malformed rates require separate evidence.
- **Cloud source safety is narrower than broad leaf claims.** Identity queues serialize one in-process user/host tuple; a nonsettling operation can block its successors. Safety scoring takes fleet-only reconnects and does not reject every NaN/future timestamp. Token verification validates issuer/audience/ES256 and schema but JWK factory construction is outside its catch. Schema retries share a deadline checked after rejection, not a timeout on each query; null/undefined rejection values can trigger another property-access error. These are source observations, not provider execution or automatic approval of a changed policy.
- **Keep the lead's cloud corrections authoritative over its leaf.** Migration registration is a single transaction, unlike selector intent persistence. SQL activity counts do not imply expiry filtering, concurrent SQLite assertions do not prove PostgreSQL outcomes or a precise losing branch, and abandonment is not a universal ban on every nonpending target control phase.
