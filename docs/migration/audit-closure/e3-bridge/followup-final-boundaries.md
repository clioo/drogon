### Concrete non-equivalences

- `runtime:call` forwards a method value such as `projectGroup.scanNested`; it does not rename `projectGroups:scanNested`. The local nested scan has ID-filtered progress and cancellation, while the remote unary path has a20s deadline and returns no stream/cancel capability.
- Web `hostedReview` and `linear` builders construct `prefix + "." + last property`, take only the first argument and use the active runtime environment. Hosted-review's explicit `repoId` wins over path and becomes `id:<id>`; receiver projections distinguish null clear, undefined no-update and truthy-only spreads. Unknown proxies may resolve empty fallbacks; those are not registered method success.
- Mentu's14 names come from `MENTU_RPC_METHODS` in `mentu-run-contract.ts`, re-exported by the recipe contract. Session approval takes a **review ID**, execution/cancellation an **approval ID**. The RPC Zod boundary is different from accepted cast-only IPC; same downstream MentuRuntime is reused by reference, not re-reviewed.
- `OptionalPositiveInt` does not enforce integer or strictly-positive semantics. Its implementation accepts finite numbers >=0, including fractions. `requiredString` does not trim. Parameter-root `null`/omission becomes `{}` before schema parsing; `params:null` on a method ignores arbitrary supplied params. These require explicit source-characterization and intended-correction tests.
- Desktop unary has no running-work cancellation path. An abortable remote unary uses a subscription and closes its request context; whether underlying work obeys the signal is a method/backend contract, not a socket-close inference.

### Payload distinctions retained

- Browser download requested includes required page/download IDs, origin, filename, nullable totalBytes/MIME, savePath and downloading status. Progress permits omitted pageId, nullable totalBytes and state; finish permits omitted pageId, nullable savePath/error and optional `remoteDestination:{workspaceRelativePath,hostLabel}`. The main pane can accept page-less finish; the client-hosted toast consumer requires exact pageId. A duplicate/ownerless finish toast is a fixture obligation, not inferred harmlessness.
- WebAuthn request contains request/page/relying-party IDs and accounts `{credentialId,displayName?,name?}[]`; response credentialId **null** means cancel. The queue has no request-ID dedup and unmount responds null to its retained pending requests.
- Session-close request is `{requestId,tabId,worktreeId,expiresAt?}`; response `{requestId,error?}`. The legacy close has only tab/worktree IDs. Zero-argument PDF notification is unrelated to `export:html-to-pdf`'s request/result.
- MJPEG carries streamId and ArrayBuffer bytes; video adds deviceId plus config/keyFrame, metadata width/height/codecId. Blob/decoder objects are local resources; no JSON schema or liveness guarantee comes from an ArrayBuffer annotation.
- UpdateStatus preserves available changelog **object|null**, optional releaseUrl/source/externallyManaged, downloading percent, downloaded version, and error message with optional version/retryable/userInitiated/nudge/recovery. Recovery is `{kind:"linux-package-install",packageType:"deb"|"rpm",reason,version}`. No `axUrl` field exists on this union.
- Skill progress operationId filters are renderer-local; begin initializes authorizing, finish removes progress. Exact nested currentSkill/index/total/name and all install host/cancel semantics remain the frozen Skills/R contract.
