# Drogon documentation screenshots

## Featured product captures

The README uses these three unmodified PNGs supplied by the developer on September 14,
2026, from the `fix-383-bot-delete-cascade` workspace associated with
[PR #552](https://github.com/clioo/drogon/pull/552). These are manual captures of a real
development session, not outputs of the fixture generator. The original images are
3248 × 2122 pixels and are stored in `docs/images/` so regenerating the fixture gallery
does not overwrite them.

| File | What it shows |
| --- | --- |
| [work-graph.png](../images/work-graph.png) | Workflow preview with a Main agent, depth-1 Implementation workers, Adversarial test, Code review, and a three-iteration limit. The sidebar shows nine agent sessions. This is the configured structure, not a completed execution result. |
| [agent-telemetry.png](../images/agent-telemetry.png) | 14 recorded entries: six blocked, two failed, three completed, two progress, and one finding. The visible agent report references PR #552 and explicitly leaves acceptance flakiness open. |
